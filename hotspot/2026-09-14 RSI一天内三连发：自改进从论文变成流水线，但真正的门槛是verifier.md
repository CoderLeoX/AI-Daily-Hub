**🔥 RSI一天内三连发：自改进从论文变成流水线，但真正的门槛是verifier**

─── 【事件速览】 ───

过去12小时，三个信源同时把"RSI（递归自我改进）"推到台前。9月12日，华为2012实验室联合华为云等团队开源平台 openJiuwen 发布双维度RSI框架，将优化对象拆为 Harness（Prompt/Skill/Tool/Rail）与 Artifacts（科研论文、算法程序），并在 WorkSwarm 蜂群办公智能体上跑通"发现失败—提出改进—执行验证—保留有效版本"的闭环。同日，CosmosMind 联合斯坦福、伯克利、MIT、清华、北大等十余家高校发布 MetaRSI-v1，宣称是首个统一 Model-RSI、Data-RSI、Harness-RSI 的元递归架构，30亿激活参数小模型在四项基准平均自我提升10.9分，SWE-bench Pro 解决率接近翻倍，六款前沿旗舰模型平均提升7.3分。生数科技 Motus2 则把行动、预测、评估三个能力放进同一个世界模型，用"生成动作→预测后果→评估结果→更新策略"的真机闭环做 RSI 初步探索，真机成功率从65%提升至75%。三者一为工程平台、一为架构语言、一为具身验证，同词不同层。

─── 【为什么重要】 ───

重要的不是"AI能改自己"这件事本身——那在 AutoML 和 prompt 自动优化时代就发生过。重要的是这次三件事都绕开了同一个历史堵点：verifier 从"人写测试"变成了"系统自带可回放证据"。

MetaRSI 的定律一说得直白：一个领域能不能形成自改进闭环，取决于该领域任务能否被检验。过去三年 RLVR 在数学和代码上的成功，本质上是在给"可验证性"定价；而 Agent 进入长任务阶段后，每一次执行都会留下轨迹、工具调用日志和沙箱结果，这些副产品第一次让"改进证据"有了规模化的原料。openJiuwen 把这一点工程化得最彻底：版本化优化对象 + 可验证执行证据，失败案例本身就是可交易的资产——办公智能体终于有了"错题本"。

商业层面的信号更清楚。华为把 RSI 架在昇腾算力上并强调"算力亲和"，说明厂商已经算清一笔账：RSI 是一个天生的算力放大器——多轮生成、执行、评测意味着 token 消耗成倍增长，谁能把重复计算压下去，谁就拿到这条链条的定价权。MetaRSI 开源 RSI-Harness 并提 Harness Genome，则是在赌成为这套流程的接口定义者。这不是学术竞赛，是基础设施和标准的卡位。

─── 【架构师解读】 ───

三者根本不在同一层，混着谈会得出错误结论。

MetaRSI 是协议层。它提出的 Loop Kernel 把"进步如何发生"抽象成与对象无关的闭环：消费反馈得到学习信号，在 Data、Harness、Model 上提出改动，交验证器裁决，结果回流为下一轮信号。Data、Harness、Model 从此是同一条骨架的三个算子。真正的结构创新在"元层"：四个 Agent 形成三层优化——算子改进目标系统，双轴编排改进算子用法，元层改进双轴编排策略本身。但必须泼一盆冷水：这仍然是三层，不是无限递归，"平方时代"是修辞而非奇点。而且前沿模型那条路线只启用了 Data 与 Harness 算子（权重不可动），所谓"旗舰模型自我进化"实质是 Harness 层面的自优化，与自家小模型跑通三算子的实验不是同一个强度。

openJiuwen 是工程层，也是当下唯一能落地的一层。它不动权重，买到了通用性——任何可通过接口调用的模型都能被它优化。代价被 MetaRSI 的定律三说破了：能力与载体无关，但成本与载体有关。留在 Harness 里的能力，每次推理都要重付一次；内化进模型只需付一次。所以 Harness-RSI → Model-RSI 的迁移方向就是成本下降方向，openJiuwen 宣布后续接入"模型优化与混合优化"，不是功能补齐，是必然的成本压力。它公开的那组性能数字——响应速度提升约16%、最慢场景超19%、缓存命中率从7.53%到14.36%、存储消耗下降两到三成——是算力亲和带来的工程收益，与"智能体变聪明了"是两件事，宣传里最容易被误读的就是这一组。

Motus2 是验证层，也是最硬的一层：它的 verifier 是物理世界。三个能力同轴是设计上的关键取舍——行动（WAM）、预测（AC-WM）、评估（VM）共用一个模型，并用 Action-first 信息流强制"先出动作、再预测后果、最后评分"，杜绝了"视频生成+动作控制"路线最常见的时序作弊（用未来帧反推当前动作）。工程细节里有真东西：触觉专家模块复用主模型已算出的中间结果，不重跑完整视频骨干，这是对"反馈频率 vs 计算开销"这个灵巧操作死结的正面回答；训练阶段只更新动作相关参数、冻结预测与评估，避免反馈信号把已学好的表征带偏。但数字要平着看：真机基础策略65%，规划单项67.5%、MBRL单项72.5%、两者叠加75%——提升真实，失败率仍有四分之一；记忆方案保留完整历史也只有57.5%成功率，低于一半，团队自己承认这是"找到最终答案之前的阶段性妥协"。这不是成熟产品，是一条方向正确的路。

最该被写进团队规范的是定律四：可信度由不可写面度量。在闭环内部，"真的变强"和"放宽了成功标准"会得到完全相同的分数，而且这种偏差从内部无法察觉、也无法靠统计纠正。这精准命中了当前所有自进化系统的死穴——自评即自欺。MetaRSI 的十有八九的增益里，有多少是激发已有能力、多少是真正引入的外部信息，定律五要求必须分开记账。

行业格局上，三条护城河互不重叠：华为卖算力与商用平台（华为云 AgentArts 已把 openJiuwen 引入），MetaRSI 卖标准与可移植的 Harness Genome，生数卖数据与本体适配——13万小时人类第一视角 ego 数据，加上把人类经验迁移到22自由度灵巧手的中间训练（仅 ego 预训练51%，加入机器人中间训练跳到84%）。谁能复制谁，一目了然：算力和标准可以被追赶，真机数据与验证环境不能。

─── 【对从业者的启示】 ───

一、先问 verifier，再谈 RSI。没有稳定、外部、不可被优化对象改写的验证信号，所谓自改进只是自嗨。宁可先用一个小而硬的评测集，也别上大而软的模型自评。

二、把"不可写面"制度化。冻结一份 golden set 且任何人（包括 Agent）无写权限，保留人工抽检和生产事故回灌通道。verifier 必须比被优化对象更难写，这一条比任何算法都重要。

三、做成本会计表。对每个能力，记录它当前承载在 Prompt、Skill、Memory 还是权重里，以及每次调用的单位成本。这张表决定你的优化方向，也决定哪些改进值得内化。

四、产品形态选"人提问题、机器跑搜索"。openJiuwen 把 RSI 做成可发起、可观看搜索树、可一键热加载插件的"实验"，这个抽象是对的：人负责定义问题与验收标准，机器负责试错。

五、每次自进化上线前做一次外部盲测。凡是"分数涨了但没人复核过用例"的版本，一律不进生产。指标自洽的系统，事故会在最贵的时刻暴露。

下一步值得盯两件事：MetaRSI 的 Data-RSI 能否真正跨领域复用（Harness Genome 的可移植性是成败点），以及各家实验室能否把物理世界的验证成本压到可承受区间——第一个真正关上的进化循环，大概率出现在自动化实验室，而不是开放环境。
