**🔥 RSI 进入工程期：验证器成了新编译器，MetaRSI 与 openJiuwen 同日交卷**

─── 【事件速览】 ───

2026年9月14日，两条互不相干的信源落在同一个点上。

研究侧：CosmosMind 联合斯坦福、伯克利、MIT、清华、北大等十余家机构发布 MetaRSI-v1（arXiv 2609.06396，9月6日提交、9月9日修订）。它把自我改进统一成一个 Loop Kernel 加 Data/Harness/Model 三个算子，再叠一层元层去改"调度策略"本身。30亿激活参数的 Qwen3.5-35B-A3B 在 Terminal-Bench 2.1、SWE-bench Pro、GPQA-Diamond 高难子集、AIME 四项上平均自提升10.9分，SWE-bench Pro 解决率接近翻倍；六款前沿闭源模型仅开 Data 与 Harness 两算子，平均 +7.3分（区间 +5.6 至 +9.2），全程无外部教师模型，目标模型同时充当提议者与裁判。

工程侧：华为2012实验室等团队的开源 Agent 平台 openJiuwen 首发双维度 RSI 框架，优化对象分 Harness（Prompt/Skill/Tool/Rail）与 Artifacts（科研论文、算法程序），配四层架构、六阶段可验证闭环与算力亲和。同日 InfoQ 挂出 QCon 上海讲稿预告：生产 checker 打94分、盲评 Meta-Evaluator 只给85分，偏差超8分自动重校 rubric。

─── 【为什么重要】 ───

RSI 不是新概念，从 Gödel Machine 到 STaR、STOP 已经喊了多年。真正的新信息是：两个独立团队在同一天，把 RSI 的瓶颈从"能不能提出更好的改进"重新定位为"能不能可信地裁决改进"。MetaRSI 五定律第一条直说"验证决定自我改进的前沿"，定律四承认"闭环内真变强和放宽标准得分完全相同，且内部无法察觉"；openJiuwen 整条链路的关键词是证据、版本、采纳与回滚；QCon 那条线干脆把"谁来审计审计员"当成核心命题。三条独立路径收敛到同一结论。

这对行业的含义比分数更重要。过去两年，能力的主要来源从参数迁移到对齐数据、推理时计算、再到执行脚手架，架构师已经习惯在 Harness 上做功。RSI 说的是：这套"人改脚手架"的循环，本身可以自动化。一旦自动化，工程资源就从"调优"变成"定义什么算好"。这也解释了为什么华为愿意把它开源——定价权会从模型调用迁移到验证与算力基建。

─── 【架构师解读】 ───

先拆架构。MetaRSI 与 openJiuwen 的表述不同，骨架惊人相似，都属同一族模式：把系统切成可写面（数据、脚手架、权重、产物）与不可写面（评测器、沙箱、发布门、证据链），优化器只能写前者，裁决只能由后者出。MetaRSI 把评测器描述为"密封、冻结后只开一次"，openJiuwen 叫"保护面"，QCon 方案叫"独立盲评"。这是可以被任何团队今晚就抄走的一条原则：优化对象和判分对象必须物理分离，且判分器的版本随证据一起冻结。

第二个可复用点是"采纳门"的形状。openJiuwen 的规则是候选必须先修好目标失败用例，再回放完整评测集确认没有改坏原本通过的题。这两个数字值得对看：参与迭代的 SWE-bench Lite Dev 23题通过率 61.0%→87.0%，而冻结 Harness 后在从未参与优化的 Evo-Bench General 64题上是 60.9%→71.9%。后者才是泛化证据，前者含过拟合成分。任何自建 RSI 管线的验收标准，只应该认后者。

第三点是元层的真实含义。"RSI 进入平方时代"是宣传口径，论文自己给出了更朴素的读法：两条改进路径的收益都会衰减，元层的作用是把仍然"值得做"的收益项从第4项推迟到第5项——是把 S 曲线的拐点往后挪一格，不是取消收益递减。同一实验里，元更新过的改进器在小预算档位上拿 +7.2 分对 +4.9 分，优势随基准可提供的增益空间放大。也就是说，元层买的是天花板，代价是复杂度、不可复现性和运维面。QCon 讲者已经踩过对应的坑：自进化的快照目录把根分区的容量与 inode 双打满，全链路集体失败。

第四点是成本模型。openJiuwen 披露的算力亲和数据很朴素却关键：TTFT 均值降15.83%、P90 降19.16%，KV Cache 命中率 7.53%→14.36%，HBM 与 DDR 峰值分别降22.82%与30.74%。RSI 的负载形状是"同一评测集反复重放"，天然高缓存命中，这意味着 RSI 的可行性首先取决于推理基建，而不是算法聪明程度。华为把这件事绑在昇腾 NPU、鲲鹏 CPU 与远端缓存池上，同时开源框架、走华为云 AgentArts 商业化——"框架开源、基建收租"，这是国产算力栈最现实的一张牌。

最后是竞争态势。MetaRSI 是高校联合体在抢范式话语权：Loop Kernel、三算子、双轴、五定律，本质是给这个领域立一套词汇表。谁定义词汇，谁的抽象会被抄进下一代工具链。二者叠加看，同一天的生产侧新闻——Perplexity 把端到端系统交给 Astra 并显著降低人工检查频率——与 RSI 的"检查是瓶颈"并不矛盾，唯一的自洽解释是：检查已经从人的注意力迁移到可编程的不写面。没完成这次迁移的团队，自动化上限就等于人的注意带宽。

─── 【对从业者的启示】 ───

1. 先造验证器，再造自进化。没有版本绑定的只读评测集，一切自我优化都只是在训练系统讨好裁判。最小可行起点是一份含真实失败用例的 JSON 评测集，加一份优化器无权读取或写入的判分规则。

2. 双层评分加偏差阈值，把评估质量本身做成监控指标。生产 checker 全量跑、盲评抽样跑，两条线的差值越阈值就触发 rubric 重校，偏差原因沉淀为下一轮素材。别让裁判和执行同源，裁判自己会漂移。

3. 只认泛化，不认拟合。候选改动必须先修好目标失败用例，再回放全量评测集验证没有改坏旧用例；冻结后在独立题集上的提升才算数。采纳与未采纳的原因都留档，失败方向比成功经验更值钱。

4. 优先动 Harness，谨慎动权重。Harness 改动零训练成本、可整机回滚、适配任何可调接口的模型；同等收益下押更便宜的载体，能力内化进权重后要回头删掉脚手架里的冗余，做减法。什么时候动权重，取决于你有没有训练基建和预算池。

5. 把预算、停止条件、快照配额、审计链和人工闸门当第一等公民设计。RSI 是拿算力换智力，一次完整实验动辄上万次模型调用；漂移从内部不可察觉，所以 HUMAN_GATE 不是过渡方案。先挑一个每周重复、结果可验收的小任务，让它连续跑对十次，再允许它改自己。
