## 🛡️ 安全通告

### 1. USN-8704-1: GNU cpio 多个漏洞
发现 cpio 在 copy-in 模式解压 tar 归档时未正确清理硬链接目标，若用户或自动化系统被诱导解压特制 tar 归档，远程攻击者可借此覆盖任意文件。
📍 *来源：[Ubuntu Security](https://ubuntu.com/security/notices/USN-8704-1)*
📅 2026-08-31

### 2. USN-8705-1: OpenZFS 漏洞
发现 OpenZFS 在 Linux 上未正确处理部分 ioctl 操作的授权检查，本地攻击者可能借此执行存储池管理操作，导致拒绝服务或数据丢失。
📍 *来源：[Ubuntu Security](https://ubuntu.com/security/notices/USN-8705-1)*
📅 2026-08-31

### 3. USN-8703-1: WebKitGTK 多个漏洞
WebKitGTK 的 Web 与 JavaScript 引擎存在多个安全问题，若用户被诱导访问恶意网站，远程攻击者可利用内存破坏等多种漏洞执行任意代码。
📍 *来源：[Ubuntu Security](https://ubuntu.com/security/notices/USN-8703-1)*
📅 2026-08-31

### 4. USN-8702-1: util-linux 多个漏洞
发现 util-linux 的 libblkid 在嵌套分区探测时存在堆 use-after-free 漏洞，可提供特制块设备镜像的攻击者可能借此导致拒绝服务或执行任意代码。
📍 *来源：[Ubuntu Security](https://ubuntu.com/security/notices/USN-8702-1)*
📅 2026-08-31
